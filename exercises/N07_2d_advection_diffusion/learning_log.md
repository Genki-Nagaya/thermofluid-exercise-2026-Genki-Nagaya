## 境界と熱収支

半セル距離，内向き正の辺別輸送，入口拡散，移流流出を式・コード・数値で対応づける．
入口・出口での熱輸送が総熱量に与える影響を書く．
収支残差と解析解誤差がそれぞれ評価する性質を書く．

- 格子と面の添字（`src/N07Transport.jl` の `thermal_fluxes!`）
  - セル中心 `x_i=(i-1/2)dx`、`y_j=(j-1/2)dy`。`T[i,j]` は x, y の順。
  - x面 `i+1/2` は `adv_x[i+1,j]`／`diff_x[i+1,j]`。添字 `1` が西境界、`nx+1` が東境界。y面も同じ（`1` が南、`ny+1` が北）。
  - 面配列には正x・正y向きの流束を書く。
- 内部面
  - 移流（風上）：`c≥0` なら左（下）のセル、`c<0` なら右（上）のセルの値に `c` を掛ける。
  - 拡散：`-κ(T_{i+1}-T_i)/dx`。
- 境界面
  - 課題の表は外向きの流束で与えられている。コードでは `outward(b, Tc, c, h)` で表のとおりに外向きの流束を求める。西・南は符号を反転して、東・北はそのまま面配列に書く。
  - 半セル距離：境界面から隣のセル中心までは `h/2` なので、固定温度・流入の拡散は `2κ(T_c-T_b)/h` になる（係数2）。
  - 入口（西・流入 `T_in=1`）：移流は外向き `-c_x T_in` で、面配列には `+c_x T_in` を書く。拡散は外向き `2κ(T_c-T_in)/dx`。
  - 出口（東・流出）：移流 `c_x T_c`（風上がセル側）、拡散 `0`（`∂T/∂x=0`）。
  - 断熱：移流・拡散とも `0`。
  - 周期：末尾セルと先頭セルを内部面と同じ式で結び、面配列の両端に同じ値を書く。
- 辺別レート（`thermal_step!`）
  - 流入を正とし、面の長さ（西東は `dy`、南北は `dx`）を掛けて辺ごとに足す。
  - `R_W = dy Σ_j J_{1/2,j}`、`R_E = -dy Σ_j J_{nx+1/2,j}`、`R_S = dx Σ_i J_{i,1/2}`、`R_N = -dx Σ_i J_{i,ny+1/2}`。移流と拡散は別々に返す。
  - 配布テストの手計算：3×4の場、`dx=0.5`、`dy=0.25` で、西の移流 `0.25×4×1 = 1`、東の移流 `-0.25×(9+10+12+11) = -10.5`。
- 安定刻み
  - `λ_T = |c_x|/dx + |c_y|/dy + κ(a_x/dx² + a_y/dy²)`、`dt = 0.8/λ_T`。
  - 固定温度・流入辺のある軸は `a=3`（半セルで係数が2倍になるため）、それ以外は `a=2`。
  - 配布テスト：`1/0.5 + 0.05(3/0.25 + 3/0.0625) = 5` → `0.8/5`。
- 熱収支（80×60、t=0→1、`Q_h = dx dy ΣT`）

  | ケース | Q(0) | Q(1) | 累積流入 | 最大の残差 |
  |---|---|---|---|---|
  | channel_fixed | 0.4 | 0.81130 | 0.41130 | 1.2e-15 |
  | channel_insulated | 0.4 | 1.24774 | 0.84774 | 2.0e-15 |
  | closed_fixed | 0.81071 | 0.43747 | −0.37325 | 2.1e-16 |
  | closed_insulated | 0.81071 | 0.81071 | 0 | 2.2e-16 |

  - channel_fixed の区間ごとの内訳：西の移流は毎区間 `+0.25`（= `c_x T_in L_y Δt` = 1×1×1×0.25）。東の移流は `-0.042 → -0.027`。上下壁の拡散は各 `-0.075〜-0.088`。入口の拡散は `+0.080 → +0.041`。
  - 入口からは移流で一定量の熱が入り、出口からは移流で出ていく。固定温度の壁は拡散で熱を奪うので、断熱壁より熱量の増え方が小さい。
  - closed_fixed：`Q(1)/Q(0) = 0.5396`。解析解の減衰率 `exp(-κ(π²/4+π²)) = 0.5397` と一致した。
- 収支残差と解析解誤差の違い
  - 収支残差は、熱量の変化と境界からの流入が離散的に合っているか（保存形の更新と、辺別レートの集計の整合）を見る。
  - 解析解誤差は、離散化が偏微分方程式の解に近いか（精度）を見る。
  - 保存形の更新なら、誤差が大きい粗い格子でも残差は丸め誤差の大きさになる。だから、残差だけでは精度は分からない。

## 二成分Burgersと安定条件

正負の風上，同じ旧場からの二成分更新，刻みを毎ステップ再評価する理由を書く．
温度の保存形とBurgersの移流形の違いも記す．

- 正負の風上（`burgers_step!`）
  - 旧速度 `u_ij≥0` なら x 方向は西の隣との差 `(w_ij - w_{i-,j})/dx`、`u_ij<0` なら東の隣との差 `(w_{i+,j} - w_ij)/dx`。y 方向は旧 `v_ij` の符号で同じように選ぶ。
  - 隣の添字は N05 の `Common.periodic_left_index`／`periodic_right_index` を再利用した。
- 二成分の同時更新
  - `u` と `v` の両方を、同じ旧場 `uold`, `vold` から更新する。運ぶ速度 `a=uold[i,j]`, `b=vold[i,j]` も旧場の値を使う。
  - 先に更新した `unew` を `v` の更新に使うと、更新の順番によって結果が変わってしまう。
- 刻みを毎ステップ求め直す理由
  - `λ_B = max(|u|/dx + |v|/dy) + 2ν(1/dx² + 1/dy²)` は速度場で決まり、速度場は時間とともに変わる。
  - 初期の速度で固定すると、速度が大きくなったときに CFL を超えるおそれがある。
  - 配布テスト：`2u, 2v` では刻みが小さくなる。
- 保存形と移流形
  - 温度は保存形 `∂T/∂t + ∇·J = 0` を面流束で離散化した。そのため熱量の変化は境界の流束だけで決まる（収支残差は丸め誤差程度）。
  - Burgers は移流形 `u ∂u/∂x + v ∂u/∂y` で、点ごとに速度を運ぶ。流束の打ち消しがないので、運動量の総和は厳密には保存されない。

## 解析解・収束・自作テスト

温度3条件とBurgersの誤差・次数，自作2群の入力・期待値・許容値とその根拠を書く．

- 公式出力（t=1、RMS誤差、3格子 40×30 → 80×60 → 160×120）

  | ケース | 誤差 | 観測次数 | 基準 |
  |---|---|---|---|
  | periodic_advection | 0.04586 → 0.02405 → 0.01232 | 0.931, 0.965 | 0.8〜1.2 |
  | periodic_diffusion | 1.540e-4 → 3.883e-5 → 9.739e-6 | 1.988, 1.995 | 1.8〜2.2 |
  | periodic_combined | 0.01909 → 0.01054 → 0.00557 | 0.857, 0.920 | 0.8〜1.2 |
  | periodic_burgers | 0.004332 → 0.002302 → 0.001190 | 0.912, 0.952 | 0.8〜1.2 |

  - 移流を含むケースは一次風上法なので1次、拡散だけのケースは中心差分なので2次になる。格子を細かくすると、次数が理論値に近づいている。
  - 移流拡散の次数が一番低いのは、粗い格子で2次の拡散誤差と1次の移流誤差が混ざっているためと考えられる。
- 自作1「開境界2条件の辺別熱収支」
  - 入力：非対称な 5×4 の場（値 0.05〜0.95）。`dx=0.3`、`dy=0.2`（dx≠dy）、`c_x=1.2`、`κ=0.04`、`T_in=1`。上下壁は固定温度0と断熱の2条件。`dt=thermal_stable_timestep` で15ステップ進める。
  - 期待値：各ステップの旧温度から、課題表の流束を「流入正・辺の長さつき」でテスト内に直接書いた式。
    - 例：西の移流 `dt·dy·ny·c_x·T_in`、南の拡散 `-dt·dx·Σ 2κT[i,1]/dy`。
    - 辺別・機構別の累積が返り値の累積と一致し、その総和が熱量の変化と一致することを確かめる。
  - 毎ステップの確認：断熱壁の拡散レートと、上下壁の移流レートがちょうど0。刻みが半セル係数（`a_y=3/2`）を含む式と一致すること。`heat_budget` に3区間の積分を渡したときの残差が `≤1e-12`。
  - 許容誤差 `1e-12`：値は O(1)、20セル×15ステップの加算の丸め誤差は 1e-14 程度なので、十分に余裕がある。
  - 検出力（実装をわざと壊して確かめた）：
    - 検出できた：入口や壁の半セル係数2を1にする誤り、東のレートの符号の反転、北の面の長さを dy にする誤り、刻みから半セル係数を落とす誤り、y方向の更新で dy の代わりに dx を使う誤り。
    - 検出できない：Burgers の誤り（対象外）。
- 自作2「温度とBurgersの解析解収束」
  - 入力：公式出力を使わずに、テスト内で t=0.5（公式は1）まで時間ループを回す。3格子 (40,30)、(80,60)、(160,120)。対象は periodic_diffusion、closed_fixed、periodic_combined、二成分 Burgers。
  - 期待値：誤差が正であること、単調に減ること、2区間の観測次数が、拡散・閉じた固定温度で 1.8〜2.2、移流を含むものと Burgers で 0.8〜1.2 に入ること。
  - 予備計算の結果：拡散 p=1.996, 2.001、閉じた固定温度 p=1.999, 1.998、移流拡散 p=0.896, 0.941、Burgers p=0.940, 0.967。
  - 検出力：
    - 検出できた：Burgers の拡散項の抜け。
    - **検出できない：x方向の風上を逆向き（下流側）にする誤り。** ν=0.05 の物理的な粘性が、下流差分が生む負の数値拡散（約 `0.6·dx/2`）を上回るので、発散せず1次の収束も保たれた。この誤りは配布の必須テスト（小さい配列での完全一致）で見つかる。

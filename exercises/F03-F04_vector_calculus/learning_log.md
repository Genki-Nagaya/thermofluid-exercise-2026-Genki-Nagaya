## 証明：div curl = 0

- 使用した定義：発散と回転の成分定義
- 成分展開：
∇·(∇×A) = ∂/∂x(∂A_z/∂y) - ∂/∂x(∂A_y/∂z)
          + ∂/∂y(∂A_x/∂z) - ∂/∂y(∂A_z/∂x)
          + ∂/∂z(∂A_y/∂x) - ∂/∂z(∂A_x/∂y)
- 混合偏微分を交換した箇所：負の符号がついた項
- 結論：∇·(∇×A) = 0

## 証明：積の発散

- 使用した定義：発散の成分定義
- 積の微分による成分展開：
∇·(φA) = ∂(φA_x)/∂x + ∂(φA_y)/∂y + ∂(φA_z)/∂z
        = (∂φ/∂x)A_x + φ(∂A_x/∂x)
          + (∂φ/∂y)A_y + φ(∂A_y/∂y)
          + (∂φ/∂z)A_z + φ(∂A_z/∂z)
        = [A_x(∂φ/∂x) + A_y(∂φ/∂y) + A_z(∂φ/∂z)] + φ[∂A_x/∂x + ∂A_y/∂y + ∂A_z/∂z]
        = A·∇φ + φ∇·A
- 必要な滑らかさと、混合偏微分の交換を使わない理由：φ と A の各成分が C^1 級　現れる微分がすべて一階で順序の違う二つの二階微分を比較する場面がなく交換する必要がない
- 結論：∇·(φA) = A·∇φ + φ∇·A

## 証明：curl curl

- ベクトルLaplacianの定義：成分ごとにスカラーの Laplacian を適用する。
- 三成分の展開：
[∇×(∇×A)]_1 = ∂/∂y(∂A_y/∂x - ∂A_x/∂y) - ∂/∂z(∂A_x/∂z - ∂A_z/∂x)
             = ∂/∂y(∂A_y/∂x) - ∂²A_x/∂y² - ∂²A_x/∂z² + ∂/∂z(∂A_z/∂x)

[∇×(∇×A)]_2 = ∂/∂z(∂A_z/∂y - ∂A_y/∂z) - ∂/∂x(∂A_y/∂x - ∂A_x/∂y)
             = ∂/∂z(∂A_z/∂y) - ∂²A_y/∂z² - ∂²A_y/∂x² + ∂/∂x(∂A_x/∂y)

[∇×(∇×A)]_3 = ∂/∂x(∂A_x/∂z - ∂A_z/∂x) - ∂/∂y(∂A_z/∂y - ∂A_y/∂z)
             = ∂/∂x(∂A_x/∂z) - ∂²A_z/∂x² - ∂²A_z/∂y² + ∂/∂y(∂A_y/∂z)
- 混合偏微分を交換した箇所と条件：
第1成分:  ∂/∂y(∂A_y/∂x) = ∂/∂x(∂A_y/∂y),  ∂/∂z(∂A_z/∂x) = ∂/∂x(∂A_z/∂z)
第2成分:  ∂/∂z(∂A_z/∂y) = ∂/∂y(∂A_z/∂z),  ∂/∂x(∂A_x/∂y) = ∂/∂y(∂A_x/∂x)
第3成分:  ∂/∂x(∂A_x/∂z) = ∂/∂z(∂A_x/∂x),  ∂/∂y(∂A_y/∂z) = ∂/∂z(∂A_y/∂y)
- 結論：∇×(∇×A) = ∇(∇·A) - ∇²A

## 前進・後退・中心差分

- 3つの差分式：
  - 前進 `D+ f(x) = (f(x+h) - f(x))/h`
  - 後退 `D- f(x) = (f(x) - f(x-h))/h`
  - 中心 `D0 f(x) = (f(x+h) - f(x-h))/(2h)`（`run.jl` の3関数）
- 参照する近傍点の違い：前進は `x` と右の `x+h`、後退は左の `x-h` と `x`、中心は左右対称の `x±h`（`x` 自身は使わない）。
- Taylor 展開から予想する収束次数：
  - `f(x±h) = f ± h f' + h²/2 f'' ± h³/6 f''' + …`
  - 前進：`D+ f = f' + h/2 f'' + O(h²)` → 1次。後退：`D- f = f' - h/2 f'' + O(h²)` → 1次（誤差の主要項は前進と逆符号）。
  - 中心：偶数次の項が打ち消し合い、`D0 f = f' + h²/6 f''' + O(h⁴)` → 2次。

|---|---:|---:|---:|

- 各公式で細格子の残差が粗格子より小さいこと：4公式とも `n=17` の残差は `n=9` の約1/4 で、配布テストの `0 < fine < coarse` と `3.0 <= 比 <= 4.8` を満たした。
- 粗格子／細格子比と中心差分の二次収束の関係：`n=9` は `h = 2/8 = 0.25`、`n=17` は `h = 2/16 = 0.125` で、h が1/2になる。中心差分の誤差は O(h²) なので、比は 2² = 4 になる。実測 4.00〜4.04 はこれと一致した。残差が 0 にならないのは公式が誤っているからではなく、打切り誤差のためである。
